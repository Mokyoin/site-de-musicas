# Top Metal Music

Projetinho para prática de **Tailwind CSS** e **JavaScript**.

# Sobre o projeto

Uma página dedicada a 3 bandas de metal famosas.

- Imagem da banda
- Nome da banda
- Botão para reproduzir a música
- Controle de play/pause através de JavaScript
- Estilização usando Tailwind CSS

# O que foi praticado

- Estruturação de páginas com HTML
- Flexbox
- Responsividade
- Tailwind CSS
- Manipulação do DOM
- `addEventListener`
- Reprodução de áudio com JavaScript
- Controle de `play()` e `pause()`
- Controle de volume com `.volume`

# Bandas

- Type O Negative
- Korn
- System of a Down
